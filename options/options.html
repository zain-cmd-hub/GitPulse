GitPulse Settings

Connect one GitHub repository. Your token stays in the extension's trusted storage context and is never sent to the website.

Important Setup Notes

  • Create a fine-grained Personal Access Token (PAT) restricted to this specific repository.
  • Grant Contents: Read and write permissions. Metadata read-only is granted automatically by GitHub.
  • Never share the token in screenshots, chat, or diagnostic reports.
  • Automatic upload requires a fresh submit click followed by the site's observed success dialog.
